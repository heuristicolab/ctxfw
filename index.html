Axiom Completeness Index (ACI)

Evalúa formalmente cualquier brief de diseño contra una Máquina de Estados Finita (FSM), variables de dominio acotadas numéricamente y una taxonomía estricta de fallos. Requiere un índice ACI ≥ 0.9000 para desbloquear la síntesis.

// 02 PISO DE SEGURIDAD NEGATIVA

Piso de Invariantes Negativas

Exige un mínimo no negociable de 5 cláusulas prohibitivas formales (usando cláusulas explícitas 'never' o 'shall never'). Si el pliego carece de prohibiciones tajantes sobre secretos, estados o memoria, es enviado a cuarentena.

¿Cómo garantiza CTXFW que podar el 72.4% de tokens no degrade el razonamiento?
CTXFW no resume con otro LLM. Utiliza gramáticas Tree-sitter para podar implementaciones privadas y redundancias cíclicas, preservando al 100% las firmas de interfaz, tipos y contratos públicos (stubs). El modelo recibe únicamente la topología matemática indispensable.
¿Qué garantías de soberanía y privacidad de datos ofrece?
El motor opera íntegramente en memoria volátil (RAM sandbox). Ningún token, esquema ni línea de código se persiste en disco ni sale a APIs externas. La inspección se ejecuta en local a latencia O(1) (<80ms).
¿Cómo se integra en un pipeline de ingeniería existente?
Como hook pre-commit determinista en Git (ctxfw spec verify) para bloquear código no conforme antes del push, o como proxy/sidecar HTTP entre tu orquestador de agentes (LangChain, LlamaIndex, MCP) y el proveedor de inferencia.
